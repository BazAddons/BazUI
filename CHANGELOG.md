## 030

- The maximized Forever map now uses the available screen width by default. Turn off Widescreen fullscreen map in Map settings to restore the original aspect ratio. Resizing waits until combat ends.
- Notifications, including the bell, toasts, panel and dropdowns, now sit beneath the fullscreen map and return to their normal layers when it closes or minimizes.
- Fixed inconsistent instances-open counts between the Codex Today and Instances pages. Both now use the same level, attunement and lockout checks; dungeons with unknown level requirements are no longer counted as open. Today's Ready to run list also includes eligible ordinary dungeons.
